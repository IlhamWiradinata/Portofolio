# Portofolio Ilham

Next.js 15 (App Router) + TypeScript.

## Menjalankan
    npm install
    npm run dev      # http://localhost:3000

## Mengubah isi
- Semua teks: `lib/data.ts`
- Foto: ganti `public/foto-ilham.jpg`
- CV: ganti `public/CV_Ilham_Wiradinata.pdf`
- Warna dan tipografi: `app/globals.css`

## Deploy
Push ke GitHub lalu import di Vercel, atau `npm run build && npm start` di VPS.
